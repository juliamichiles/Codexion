| Function                   | Purpose                                            | Arguments                                                                                                                                                                                                             | Return value                                                                     |
| -------------------------- | -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `pthread_create()`         | Create a new thread                                | `pthread_t *thread` — where to store thread ID<br>`const pthread_attr_t *attr` — thread attributes, usually `NULL`<br>`void *(*start_routine)(void *)` — function the thread runs<br>`void *arg` — argument passed to that function | `int` — `0` on success, error number on failure                                  |
| `pthread_join()`           | Wait for a thread to finish                        | `pthread_t thread` — thread to wait for<br>`void **retval` — where to store thread's return value, usually `NULL`                                                                                                         | `int` — `0` on success, error number on failure                                  |
| `pthread_mutex_init()`     | Initialize a mutex                                 | `pthread_mutex_t *mutex` — mutex to initialize<br>`const pthread_mutexattr_t *attr` — attributes, usually `NULL`                                                                                                          | `int` — `0` on success, error number on failure                                  |
| `pthread_mutex_lock()`     | Lock a mutex                                       | `pthread_mutex_t *mutex` — mutex to lock                                                                                                                                                                              | `int` — `0` on success, error number on failure                                  |
| `pthread_mutex_unlock()`   | Unlock a mutex                                     | `pthread_mutex_t *mutex` — mutex to unlock                                                                                                                                                                            | `int` — `0` on success, error number on failure                                  |
| `pthread_mutex_destroy()`  | Destroy a mutex                                    | `pthread_mutex_t *mutex` — mutex to destroy                                                                                                                                                                           | `int` — `0` on success, error number on failure                                  |
| `pthread_cond_init()`      | Initialize a condition variable                    | `pthread_cond_t *cond` — condition variable<br>`const pthread_condattr_t *attr` — attributes, usually `NULL`                                                                                                              | `int` — `0` on success, error number on failure                                  |
| `pthread_cond_wait()`      | Wait for a condition; releases mutex while waiting | `pthread_cond_t *cond` — condition variable<br>`pthread_mutex_t *mutex` — **locked** mutex associated with condition                                                                                                      | `int` — `0` on success, error number on failure                                  |
| `pthread_cond_timedwait()` | Wait for a condition with a timeout                | `pthread_cond_t *cond` — condition variable<br>`pthread_mutex_t *mutex` — **locked** mutex<br>`const struct timespec *abstime` — absolute timeout                                                                             | `int` — `0` if signalled, `ETIMEDOUT` if timeout expires, otherwise error number |
| `pthread_cond_signal()`    | Wake **one** waiting thread                        | `pthread_cond_t *cond` — condition variable                                                                                                                                                                           | `int` — `0` on success, error number on failure                                  |
| `pthread_cond_broadcast()` | Wake **all** waiting threads                       | `pthread_cond_t *cond` — condition variable                                                                                                                                                                           | `int` — `0` on success, error number on failure                                  |
| `pthread_cond_destroy()`   | Destroy a condition variable                       | `pthread_cond_t *cond` — condition variable to destroy                                                                                                                                                                | `int` — `0` on success, error number on failure                                  |
